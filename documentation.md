\# Документация проекта



\## Назначение проекта

Проект представляет собой двухмерную игру Castlevania Chrome Dino Game на движке Godot Engine.



\## История изменений проекта

1\. Initial commit (693cc80, 178b999) — инициализация репозитория.

2\. Обновления README.md (182c739, 1616679, 01d9d11) — базовая настройка описания.

3\. Новые версии игры (e3felca, caec63a) — активная разработка Castlevania Chrome Dino Game.

4\. Создание классов (80e34f6) — добавлены конкретные классы для Врагов (Enemies) и Препятствий (Obstacles).

5\. Pre-beta release (227b0f8) — предрелизная сборка.

6\. Финальный коммит (c87d96f) — последнее обновление README.md.
